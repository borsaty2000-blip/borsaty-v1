# Backtest & Walk-Forward Validation Engine (Phase ح)

## 1. Core Principle

> We do NOT claim "high accuracy". We **PROVE** it with historical data,
> walk-forward validation, and Wilson Confidence Intervals.

Every signal generated by `TradePlanEngine` must be:
1. **Backtested** on ≥5 years of historical data
2. **Validated** using Walk-Forward (rolling window) analysis
3. **Reported** with Hit Rate + Wilson CI (95%)
4. **Segregated** by regime, timeframe, and pattern type

> [!IMPORTANT]
> **No Look-Ahead**. At bar index `i`, the pipeline receives ONLY `candles[0:i]`.
> Future bars are never accessible. Verified by 10 dedicated unit tests.

## 3. BacktestEngine

### Algorithm

```
Step 1: Validate input (need ≥ warmup_bars + 2 candles)
Step 2: For i in range(warmup_bars, len(candles)):
          past = candles[0:i]          ← ONLY past data
          full = orchestrator.run(past) ← full 7-engine pipeline
          if TradePlanEngine → actionable signal:
              record SignalRecord(entry, stop, targets, regime, …)
Step 3: Forward-scan each signal:
          scan candles[bar_index : bar_index + 30]:
            HIT_T3 if price hits T3 (before stop)
            HIT_T2 if price hits T2 (before stop)
            HIT_T1 if price hits T1 (before stop)
            STOPPED if price hits stop first
            EXPIRED if neither within 30 bars
Step 4: Aggregate metrics (hit_rate, profit_factor, sharpe, Wilson CI, …)
```

### Outcome Priority

| Priority | Condition | Outcome |
|----------|-----------|---------|
| 1st | Price ≥ T3 (bullish) before stop | `HIT_T3` |
| 2nd | Price ≥ T2 (bullish) before stop | `HIT_T2` |
| 3rd | Price ≥ T1 (bullish) before stop | `HIT_T1` |
| 4th | Price ≤ Stop (bullish) | `STOPPED` |
| 5th | Neither within 30 bars | `EXPIRED` |

### API

```python
from backtest.engine import BacktestEngine

engine = BacktestEngine()
result = engine.run(
    symbol="COMI",
    timeframe="1D",
    candles=candles,     # chronological OHLCV list
    warmup_bars=250,
)
print(result.total_signals)
print(result.metrics.hit_rate_t1)
print(result.metrics.wilson_ci_95_t1)   # [0.54, 0.79]
```

## 4. WalkForwardValidator

Splits the full history into overlapping windows (default: 500 bars, step 250)
and runs `BacktestEngine` on each window.

### Metrics

| Metric | Formula | Target |
|--------|---------|--------|
| Stability Score | `1 - std(hit_rates) / mean(hit_rates)` | ≥ 0.70 |
| WF Efficiency | `last_window_HR / first_window_HR` | ≥ 0.75 |
| Verdict | Stable if both above threshold | `stable` / `unstable` |

### API

```python
from backtest.walk_forward import WalkForwardValidator

validator = WalkForwardValidator(window_size=500, step_size=250)
result = validator.validate("COMI", "1D", candles)
print(result.verdict)         # "stable"
print(result.message_ar)      # "أداء مستقر عبر 3 نوافذ زمنية مختلفة"
print(result.overall["stability_score"])   # 0.92
```

## 6. Insufficient Data Rule

> [!WARNING]
> If `total_signals < 30`, **no hit rate is published**.
> The report displays: **"بيانات غير كافية — الإشارات أقل من 30"**
> The JSON contains `data_quality.sample_size_adequate = false`.

---

## 7. Wilson Confidence Intervals

All hit rates are accompanied by 95% Wilson Score Intervals:

$$CI = \frac{\hat{p} + \frac{z^2}{2n} \pm z\sqrt{\frac{\hat{p}(1-\hat{p})}{n} + \frac{z^2}{4n^2}}}{1 + \frac{z^2}{n}}$$

where `z = 1.96` for 95% confidence.

## 8. FastAPI Endpoints

### `POST /backtest/run`

Run a full backtest on provided candles.

**Request:**
```json
{
  "symbol": "COMI",
  "timeframe": "1D",
  "candles": [...],
  "warmup_bars": 250,
  "language": "ar",
  "include_walk_forward": true
}
```

**Response:** `BacktestResult` + `WalkForwardResult` + dual-language report.

### `POST /backtest/leaderboard`

Rank multiple symbols by backtest performance.

**Request:**
```json
{
  "candles_by_symbol": { "COMI": [...], "AAPL": [...] },
  "sort_by": "hit_rate_t1",
  "min_signals": 30,
  "limit": 20
}
```

|-------|--------|-------------|

## 11. Non-Negotiable Rules

1. **NO LOOK-AHEAD.** `past = candles[0:i]` strictly. Tested by 10 dedicated tests.
2. **< 30 signals → `insufficient_data`**, no hit rate displayed.
3. All metrics computed **deterministically**, no rounding errors.
4. **Wilson CI** computed for all published hit rates.
5. Arabic + English reports via `BacktestReport` (same contract as Phase ز).
6. Backtest results **versioned** — engine version `1.0.0`.
7. **Zero regressions** on prior 472 tests.
